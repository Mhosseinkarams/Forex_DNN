# HistoricalDatasetBuilder

The `HistoricalDatasetBuilder` (`Market_Data_Pipeline/historical_dataset_builder.py`) is the centralized offline pipeline responsible for converting raw historical OHLCV data into unified, versioned, and audited machine learning datasets. It serves as the single source of truth for ML training data in the Forex_DNN framework. All future models must train exclusively on datasets generated by this builder.

## Pipeline Architecture

For every candle in each sliding window, the builder coordinates the following sequential steps:

```text
Raw Historical Data (Parquet/CSV)
              │
              ▼
    [ Indicator Calculation ]  (IndicatorEngine)
              │
              ▼
    [ Structural Engines ]     (MarketStructureEngine & SupplyDemandEngine)
              │
              ▼
    [ Sliding Windowing ]      (Configurable window_size & window_stride)
              │
              ▼
    [ Labeling Coordinator ]   (LabelEngine -> MarketStateLabeler)
              │
              ▼
    [ Dynamic Feature Extr. ]  (FeatureRegistry & FeaturePipeline)
              │
              ▼
    [ Quality Verification ]   (DatasetValidator)
              │
              ▼
   Versioned Output Files      (Parquet, CSV, Manifest JSON)
```

1. **Indicator Calculation**: Calculates EMAs, ATR, and other technical indicators needed.
2. **Structural Processing**: Runs `MarketStructureEngine` and `SupplyDemandEngine` to identify swings, protected levels, BOS, CHOCH, and supply/demand zones.
3. **Sliding Window Generation**: Generates configurable sliding windows (default size of 35 candles, step size of 1 candle).
4. **Objective Labeling**: Calls the `LabelEngine` (with custom labeling strategies like `MarketStateLabeler`) to determine the training target label. If the LabelEngine returns `None` due to ambiguity, the sample is discarded.
5. **Dynamic Feature Extraction**: Queries the `FeatureRegistry` for all active features (including positional features like `distance_to_invalidation_level` and `risk_reward_estimate`) and extracts scale-invariant values at the window endpoint strictly.
6. **Data Quality Verification**: Audits the completed dataset using `DatasetValidator` for missing values, duplicates, timestamp monotonicity, feature variance, and target/symbol imbalances.

## Key API Methods

### `__init__(...)`

```python
def __init__(
    self,
    input_dir: str = "HistoricalData",
    output_dir: str = "output",
    window_size: int = 35,
    window_stride: int = 1,
    timeframe: str = "M5",
    version: Optional[str] = None,
    registry: Optional[FeatureRegistry] = None,
    label_engine: Optional[LabelEngine] = None,
    ms_engine: Optional[MarketStructureEngine] = None,
    sd_engine: Optional[SupplyDemandEngine] = None
)
```

### `build_dataset(max_workers: Optional[int] = None)`

Discovers relevant historical symbol files, processes them (supporting parallel multithreaded workers via `concurrent.futures`), runs data quality validation checks, prints a beautiful Quality Summary Report, and serializes output files.

- **`max_workers`**: Limits the number of parallel symbol processing threads. Set to `1` for single-thread sequential debugging.

## Dataset Versioning Pattern

To ensure complete reproducibility during experiments, the builder manages dataset versions automatically (e.g. `dataset_v001.parquet`, `dataset_v002.parquet`, etc.) and records a detailed JSON manifest containing:

- Window configuration parameters.
- Active feature counts and active feature configuration hashes.
- Absolute row counts and class distributions (imbalances).
- Missing/NaN ratios, duplicates ratios, and a list of zero-variance constant features.
- Exact generation timestamp and software versions of underlying engines.

## Usage Example

```python
import logging
from Market_Data_Pipeline.historical_dataset_builder import HistoricalDatasetBuilder

logging.basicConfig(level=logging.INFO)

# Initialize builder on EURUSD and GBPUSD 5-minute data
builder = HistoricalDatasetBuilder(
    input_dir="HistoricalData",
    output_dir="output",
    window_size=35,
    window_stride=1,
    timeframe="M5"
)

# Run parallel build with up to 4 worker threads
df, metadata = builder.build_dataset(max_workers=4)

print(f"Dataset compiled! Version: {metadata['version']}, Rows: {len(df)}")
```
